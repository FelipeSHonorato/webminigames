# Avatares

Coloque aqui as imagens que os jogadores podem escolher em **Meu perfil → Usar avatar**.

- Formatos: PNG, JPG, WEBP, GIF ou SVG. De preferência **quadradas** (ex.: 512×512); imagens retangulares são recortadas ao centro.
- Nomes só com letras, números, `_`, `.` e `-`, sem espaços nem acentos (ex.: `avatar_02.png`).
- Depois de adicionar ou remover imagens, rode `npm run avatars` para atualizar o `avatars.json` (o `npm start` e o `npm test` já fazem isso).
- Faça commit das imagens **e** do `avatars.json`.

O `avatars.json` é gerado automaticamente: não precisa editar à mão.
