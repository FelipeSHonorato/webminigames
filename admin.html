Jogos do site

Desligar um jogo impede os jogadores de entrar nele. Os pontos não são removidos: continuam no ranking de cada jogo, no ranking geral e no perfil de cada jogador. Você continua podendo abrir jogos desligados.

    Neste protótipo a chave é gravada só neste navegador. Para valer para todos os jogadores, o estado precisa ficar no servidor.
